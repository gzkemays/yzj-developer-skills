# P6 Review 材料模板（dev-session）

> 按主文件「变更分级」二选一输出；用法见 `references/p6-p8-developer-gates.md`。

## ARCH 架构级 —— 深度评审材料

```
## Review 材料（ARCH 架构级）
### 变更摘要        [文件清单 + 关键设计决策 + 为什么这样设计]
### 架构影响        [受影响的业务域/模块/契约，与既有架构的关系]
### AI Review 报告  [P4 逐维度结论 + 回溯扫描结果 + api-contract-checker 结果]
### P5 自测结果     [编译/preview 验证摘要 + 截图（前端）]
### 测试用例        [design/{slug}-testcases.md 链接——请确认覆盖面与 TC-5 回归范围，可要求增删用例]
### 需要决策        [AI 不确定、需开发者拍板的项]
---
请逐项审阅。通过 → 进入 P7；有问题 → 描述，我修复后重走 P4。
```

## NORMAL 常规级 —— 知会式确认摘要（10 行内）

```
## 变更知会（NORMAL 常规级）
- 变更：[一句话 + 文件数]
- 自审：P4 reviewer 全维度通过 / 回溯扫描 [N] 处同类已处理
- 自测：[编译/preview 结论] ｜ 用例：[testcases 文档链接或内联验证点，含回归范围]
- 风险：[无 / 一句话]
---
过目后任意回复即视为确认（如需深度 Review 请说"升级 ARCH"）。
```
